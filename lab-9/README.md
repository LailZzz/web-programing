# Лабораторна робота 9 — «Акустична варта»

Простий Angular-застосунок зі списком датчиків: додавання, видалення, зміна статусу.

## Запуск

```bash
npm install
npx ng serve --open
```

## Збірка для GitHub Pages

```bash
npx ng build --base-href /web-programing/lab-9/dist/acoustic-watch/browser/
```
