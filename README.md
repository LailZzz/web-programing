# Мої 3 найкращі міста світу

Лабораторна робота 1 з дисципліни «WEB-програмування».
Статичний багатосторінковий блог про три міста: Ніцца, Токіо, Прага.

Автор: Муханов Володимир Сергійович, група КН-42.

## Сторінки

- `index.html` — головна сторінка
- `city-nice.html` — Ніцца
- `city-tokyo.html` — Токіо
- `city-prague.html` — Прага
- `form.html` — форма «Запропонувати місто»
- `images/` — зображення міст
