# Лабораторна робота 3 — «Акустична варта»

Адаптивна верстка (SCSS, Flexbox, CSS Grid, Media Queries).

## Структура

- `index.html` — розмітка
- `scss/` — вихідні стилі (`main.scss` + partials `_variables`, `_mixins`, `_base`, `_layout`, `_components`)
- `css/main.css` — результат компіляції SCSS
- `assets/images/` — зображення

## Компіляція SCSS

```bash
npm install
npm run build   # одноразово
npm run sass    # режим watch
```
