# Лабораторна робота 6 — «Акустична варта»

Відображення та фільтрація сенсорів у DOM. Продовження сторінки з лабораторної 4.

## Структура

- `index.html` — нова секція «Активні сенсори» після «Поточного моніторингу»
- `scss/` — вихідні стилі, `css/main.css` — результат компіляції
- `js/sensors.js` — дані сенсорів, `createSensorCard`, `renderSensors`, `applyFilters`

## Запуск

```bash
npm install
npm run build
```

Відкрити `index.html` через Live Server.
